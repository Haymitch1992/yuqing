# 交控科技舆情日报

每个自然日为交控科技（688015）生成一份舆情报告。默认每天下午 17:00（上海时间）自动生成并发送到已配置的收件人；也可以手动生成、预览后再发。

采集范围：

- 行情：腾讯行情，取报告日当天或之前的最后一个交易日
- 公告：上交所当日披露
- 新闻：东方财富搜索，以及网易、同花顺、腾讯自选股的公开列表。只保留标题含「交控科技」或「688015」的结果

今日头条、天眼查、雪球的公开页面当前打不开，不计入日报。情感按标题规则判断，热度是同题条数。

预览页可以「导出 Word」。下载的文件使用和页面相同的三章和统计数字。发送到邮箱时，完整报告以同一份 Word 作为附件发出，正文里不再放预览链接。

需求说明见 [docs/需求说明.md](docs/需求说明.md)。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:38471](http://127.0.0.1:38471)。

默认每天下午 17:00（上海时间）自动生成并发送当天报告。进程要保持运行，定时才会执行。也可以在首页手动选择日期生成。

## 发信

在「发信设置」里填写 SMTP。QQ 邮箱示例：主机 `smtp.qq.com`，端口 `465`，勾选 SSL，密码填授权码。授权码保存在本机 `data/settings.json`，这个目录不会进仓库。

可以先给自己发一封测试信，再回到报告预览页确认发送。

## 容器化部署

服务器上用 Docker 常驻运行（含 17:00 自动生成并发送）。详细步骤见 [docs/部署说明.md](docs/部署说明.md)。

```bash
mkdir -p data && sudo chown -R 1001:1001 data
export APP_ORIGIN=http://你的服务器IP:38471
docker compose up -d --build
```

访问 `http://服务器地址:38471`。报告与 SMTP 设置保存在宿主机 `./data`，重建镜像不会丢。
