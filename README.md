# 交控科技舆情日报

每个自然日为交控科技（688015）生成一份舆情草稿。打开预览之后，才能发到指定邮箱。定时任务不会自动发信。

采集范围：

- 行情：腾讯行情，取报告日当天或之前的最后一个交易日
- 公告：上交所当日披露
- 新闻：东方财富搜索里，标题含「交控科技」或「688015」的结果

雪球、今日头条、腾讯自选股不在这次采集里。情感按标题规则判断，热度是同题条数。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:38471](http://127.0.0.1:38471)。

默认每天 20:30（上海时间）生成当天草稿。进程要保持运行，定时才会执行。也可以在首页手动选择日期生成。

## 发信

在「发信设置」里填写 SMTP。QQ 邮箱示例：主机 `smtp.qq.com`，端口 `465`，勾选 SSL，密码填授权码。授权码保存在本机 `data/settings.json`，这个目录不会进仓库。

可以先给自己发一封测试信，再回到报告预览页确认发送。

邮件里的预览链接默认用当前访问地址。如果要从别的机器打开，设置环境变量 `APP_ORIGIN`，例如 `http://127.0.0.1:38471`。
